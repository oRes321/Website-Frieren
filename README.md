# Сайт про Фрірен (Практична робота №1)

## Опис проєкту
Цей проєкт є виконанням практичної роботи №1 з дисципліни "Створення Web-сайтів". Головна тематика сайту — аніме "Проводжаюча в останній шлях Фрірен" (Sōsō no Frieren). Сайт складається з трьох сторінок, які демонструють використання основних HTML-тегів, семантичної верстки, форм та медіа-елементів.

## Що реалізовано
- **index.html**: Головна сторінка з інформацією про аніме, списками, таблицею та зображенням.
- **pages/about.html**: Сторінка з відео (трейлер) та аудіо (головна музична тема).
- **pages/contact.html**: Сторінка з формою зворотного зв'язку, яка включає всі необхідні поля та валідацію.
- **app.js**: Невеликий скрипт, який додає інтерактивність (зміна тексту на кнопці).
- **README.md**: Цей файл з інструкцією.

## Як запустити
1. Завантажте або склонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Firefox, Edge).
3. Для коректного відображення медіа (відео/аудіо) переконайтеся, що файли в папці `assets/media/` існують (або замініть їх на власні/онлайн-посилання).

## Важливо про медіафайли
У папці `assets/media/` за замовчуванням очікуються файли:
- `frieren-trailer.mp4` та `frieren-trailer.webm`
- `frieren-theme.mp3` та `frieren-theme.ogg`
Якщо у вас їх немає, ви можете:
1. Завантажити трейлер з YouTube та сконвертувати.
2. Або замінити значення `src` у тегах `<source>` на прямі посилання з інтернету.
